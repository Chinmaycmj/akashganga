## 🌟 Key Features

### 1. The 14-Stage Zoom Out to Infinity Journey
A continuous interactive voyage spanning 22 physical orders of magnitude ($10^6\text{ m} \to >10^{26}\text{ m}$):
1. **Earth's Core & Interior ($10^6\text{ m}$)**: Crust, mantle, outer liquid core, inner solid core, and geodynamo.
2. **Earth's Surface & Atmosphere ($10^7\text{ m}$)**: Troposphere through exosphere, magnetosphere, and planetary habitability.
3. **The Earth–Moon System ($10^8\text{ m}$)**: Barycentric orbit, tidal locking, lunar phases, and true scale distance.
4. **The Solar System ($10^{12}\text{ m}$)**: Sun, 8 planets, Asteroid & Kuiper belts, Oort Cloud, and Keplerian orbital speeds.
5. **Stars & Stellar Evolution ($10^{16}\text{ m}$)**: Main sequence, red giants, planetary nebulae, Chandrasekhar limit ($1.4\ M_\odot$), and neutron stars.
6. **Exoplanets & Habitable Worlds ($10^{17}\text{ m}$)**: Circumstellar habitable zones, transit photometry, and biosignatures.
7. **Nebulae & Interstellar Medium ($10^{18}\text{ m}$)**: Emission/reflection nebulae and Jeans gravitational instability.
8. **The Milky Way Galaxy ($10^{21}\text{ m}$)**: Barred spiral arms, Sagittarius A* ($4.15 \times 10^6\ M_\odot$), and dark matter halo.
9. **Other Galaxies ($10^{22}\text{ m}$)**: Hubble tuning fork, Andromeda (M31), and galactic collision dynamics.
10. **Galaxy Groups & Clusters ($10^{23}\text{ m}$)**: Local Group, Virgo Cluster, intra-cluster medium, and virial mass.
11. **The Cosmic Web ($10^{24}\text{ m}$)**: Large-scale structure filaments, voids, and dark matter scaffolds.
12. **The Observable Universe ($10^{26}\text{ m}$)**: Cosmic Microwave Background, particle horizon ($\sim 93\text{ billion light-years}$).
13. **Beyond the Observable Horizon ($10^{28}\text{ m}$)**: Cosmic inflation, spatial curvature bounds ($|\Omega_k| < 0.005$), and causal horizons.
14. **Dimensions, Quantum & Multiverse ($10^{30}\text{ m}$)**: General Relativity, 4D Tesseract projection, and Tegmark Multiverse levels.

### 2. The 8 Signature Interactive Labs
- **Lab 1: Black Hole Explorer (`/labs/black-hole`)**: Real-time Schwarzschild radius solver ($R_s = \frac{2GM}{c^2}$), photon sphere ($1.5 R_s$), ISCO ($3 R_s$), and gravitational lensing deflection.
- **Lab 2: Orbital Mechanics Simulator (`/labs/orbital-mechanics`)**: Vis-viva equation ($v^2 = GM(\frac{2}{r} - \frac{1}{a})$), semi-major axis, eccentricity, and perihelion/aphelion velocities.
- **Lab 3: Comparative Planetary Scale (`/labs/planet-comparison`)**: True physical diameter, surface gravity, escape velocity, and atmospheric comparisons.
- **Lab 4: Stellar Evolution & Lifecycles (`/labs/stellar-evolution`)**: Initial stellar mass slider ($0.1\ M_\odot$ to $100\ M_\odot$) predicting core fusion stages and remnant fates.
- **Lab 5: Spacetime Curvature & Waves (`/labs/spacetime-curvature`)**: 3D rubber-sheet spacetime mesh deformation and quadrupole waves.
- **Lab 6: Cosmic Expansion & Redshift (`/labs/cosmic-expansion`)**: Hubble-Lemaître law ($v = H_0 d$), cosmological redshift ($z$), lookback time, and scale factor $a(t)$.
- **Lab 7: Dimensions & Projections (`/labs/dimensions-explorer`)**: Interactive 4D hypercube (Tesseract) rotating through $XW$ and $YZ$ planes projected to 3D and 2D.
- **Lab 8: Multiverse Hypotheses Comparator (`/labs/multiverse`)**: Systematic comparison of Level I–IV Tegmark multiverse models with falsifiability criteria.

### 3. Navagraha Observatory (`/navagraha`)
- Detailed analytical dossiers for Surya, Chandra, Mangala, Budha, Brihaspati, Shukra, Shani, Rahu, and Ketu.
- **Epistemological Demarcation**: Rahu and Ketu are strictly treated as mathematical orbital intersection nodes (*pata*), not physical planetary bodies.
- Dignity matrices: Exaltation (Uchha with exact degree), Debilitation (Neecha), Moolatrikona, and Own Signs.
- Traditional aspects (Drishti), friendship relationships (Mitra, Sama, Shatru), gemstones, Bija mantras, and classical textual citations.

### 4. 360° Rashi & Nakshatra Atlas (`/rashi-nakshatra`)
- 12 Rashis with element, modality, and ruling lords.
- 27 Nakshatras ($13^\circ 20'$ each) anchored to real background stars (Spica, Regulus, Aldebaran, etc.).
- All 108 Nakshatra Padas ($3^\circ 20'$ each) mapped to their respective **D-9 Navamsha sign**, ruling lord, and sound syllable.
- Interactive celestial coordinate solver computing Rashi, degree, Nakshatra, Pada, and Navamsha in real time.

### 5. Jyotisha Chart Lab (`/chart-lab`)
- Analytical Keplerian ephemeris computing sidereal longitudes, GMST, Local Sidereal Time, and Lagna (Ascendant).
- Visualizes both **North Indian (Diamond / House-Fixed)** and **South Indian (Square / Zodiac-Fixed)** Kundli charts.
- Real-time switch between **D-1 Rashi Chart** and **D-9 Navamsha Chart**.
- User-selectable Ayanamshas: **Lahiri (Chitra Paksha)**, **B.V. Raman**, **KP**, or **Tropical (Sayana)**.

### 6. Ancient Mathematical Astronomy Lab (`/ancient-math`)
- **Bhaskara I's Rational Sine Approximation (629 CE)**:
  $$\sin x \approx \frac{16x(\pi - x)}{5\pi^2 - 4x(\pi - x)}$$
  Calculates values with fractional error vs. modern trigonometric functions (error $< 1.8\%$).
- **Aryabhata’s 24 Sine Differences (499 CE)**: First-quadrant table ($R = 3438'$) with Sanskrit mnemonics (*makhi, bhakhi...*).
- **Kuttaka Diophantine Solver**: Euclidean back-substitution solver for indeterminate equations $ax - by = c$ used to calculate planetary conjunctions.
- **Ahargana Epoch Counter**: Days elapsed from the Kaliyuga epoch (3102 BCE) to any given date.

### 7. Dual-Track Cosmic Time Machine (`/cosmic-time`)
- Side-by-side comparison of traditional Indian cosmic time (Truti $\to$ Yugas $\to$ Mahayuga $\to$ Manvantara $\to$ Kalpa $= 4.32\text{ Gyr}$) with modern $\Lambda$CDM cosmic chronology (Planck Epoch $\to$ Inflation $\to$ Recombination $\to$ Present Day $\to$ Heat Death).
- Relativistic gravitational time dilation ($\Delta t' = \Delta t \sqrt{1 - \frac{2GM}{rc^2}}$) compared with traditional Puranic narratives of dilated time in higher realms.

### 8. Sanskrit Source Knowledge Library (`/library`)
- Verified Devanagari Sanskrit verses, IAST transliterations, and attributed English translations from:
  - *Aryabhatiya* (Diurnal axial rotation of Earth)
  - *Surya Siddhanta* (Cosmic Yuga arithmetic)
  - *Brahmasphutasiddhanta* (Universal gravitational attraction)
  - *Brihat Parashara Hora Shastra* (Graha natures and dignities)
  - *Rigveda* (Nasadiya Sukta, 10.129 creation hymn)
  - *Vedanga Jyotisha* (Solstices and 5-year lunisolar cycles)
- One-click copy tools and academic notes.

### 9. 10-Stage Prerequisite Curriculum (`/curriculum`)
- Structured learning map from beginner to independent practitioner with learning objectives, key terms, misconception checks, and mastery quizzes.
- Progress tracked via `UserProgressContext` and saved to `localStorage`.

### 10. Contextual AI Cosmic Tutor (`/tutor`)
- Specialized pedagogical tutor offering multi-depth answers (Beginner, Intermediate, Advanced) across astrophysics, Sanskrit texts, and Jyotisha algorithms.

### Installation & Run

```bash

git clone https://github.com/Chinmaycmj/akashganga.git
cd akashganga

# 2. Install dependencies
npm install

# 3. Run all 647 automated verification tests
npm test

# 4. Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your web browser.

### Production Build

```bash
npm run build
npm run start
```
